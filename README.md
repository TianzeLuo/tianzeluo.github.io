# Tianze Luo — Personal Portfolio

Personal website of Tianze Luo, featuring selected projects, a CV, and open-source work.

The site is statically generated with **Astro 5**, **MDX**, and **Tailwind CSS 4**. It is bilingual (English / 中文), defaults to dark mode, and includes downloadable one-page CV PDFs.

## Pages

- `/en/`, `/zh/` — home
- `/en/projects/`, `/zh/projects/` — project index and four project pages
- `/en/cv/`, `/zh/cv/` — CV with PDF download

## Projects

- **OmniStudio** — a cross-platform Qt workspace for notes, code, AI assistance, and online judging
- **DSH Plugin Suite** — plugins for academic search, paper reading, and session workflows
- **Yizhi** — a local-first personal knowledge workbench with cited Q&A
- **Deep RL Practice** — a unified PyTorch training framework for classic RL algorithms
