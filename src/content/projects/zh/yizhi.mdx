## 项目概述

易知是一个本地优先的个人知识工作台。上传文档后，系统完成解析、增量索引和发布，再通过带引用的知识问答、Assistant 对话与 Skill 工作流使用这些知识。

项目的重点不是“让模型读一堆文件”，而是让每个回答都能回到固定的来源版本和原文位置。

## 解决的问题

个人资料往往散落在 PDF、课件、笔记和网页里。普通检索只能给出相似段落，却很难说明答案来自哪一版文档、哪一页。易知把来源版本、定位信息和引用身份一起保存下来，回答时展示引用、限制与原文片段。

## 主要功能

- **数据来源**：上传文档，等待解析、索引和发布；保留来源版本与定位信息。
- **知识问答**：基于当前 Space 的已发布文档回答，展示引用、限制和可点击的原文定位。
- **Assistant 对话**：保留会话、运行记录与引用；根据请求选择合适的 Skill 或知识工具。
- **个人 Skill**：通过草稿、校验、评估和审批创建个人 Skill，不能覆盖内置 Skill。
- **长期记忆**：从会话中提炼事实、偏好和工作模式，在后续对话中按需检索。
- **本地 Agent 工作区**：在受路径约束和审批策略保护的前提下读取文件、写入文件或执行命令。

## 技术实现

后端使用 Python 与 FastAPI，前端使用 React 与 TypeScript。PostgreSQL 保存数据、版本和索引，Redis 承载后台任务队列，Embedding 与 Reranker 作为独立服务运行，整个系统通过 Docker Compose 启动。

默认的 fake provider 返回确定性的抽取式回答，便于先验证完整流程；配置外部 Chat Provider 后可以使用真实模型。来源清单、SHA-256 校验、路径 containment 与审批策略共同约束数据边界。
