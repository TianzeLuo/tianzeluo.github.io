## 项目概述

DSH（DeepSeek Harness）是一个可扩展的智能体工作环境。这个合集把我为它写的插件整理在一起，覆盖学术检索、论文阅读、会话侧栏、桌面通知和数学公式渲染。

插件都围绕同一条原则：补上真实工作流里的缺口，而不是把模型再包一层。能在宿主接缝上解决的问题，就不额外消耗模型回合；需要长期开启的能力，尽量做成按项目开启。

## 插件分类

### 研究与阅读

- [**dsh-academic-search**](https://github.com/tianzeluo/dsh-academic-search)：跨 arXiv、OpenAlex、Semantic Scholar 和 Crossref 的学术检索，支持论文身份归并、有界引用链与 arXiv 原文交接。
- [**dsh-paper-reader**](https://github.com/tianzeluo/dsh-paper-reader)：论文解读模式，生成带页码与章节锚点的解读报告，并基于同一份解析产物回答追问。

### 会话与工作流

- [**dsh-btw-sidebar**](https://github.com/tianzeluo/dsh-btw-sidebar)：Codex 风格的 `/btw`，把当前会话分叉到原生右侧栏继续聊。
- [**dsh-away-notify**](https://github.com/tianzeluo/dsh-away-notify)：只有当你不在页面上时，才为完成、出错、等待审批等事件弹桌面通知。
- [**dsh-commandcode-quota**](https://github.com/tianzeluo/dsh-commandcode-quota)：在会话页头查看 Command Code 套餐的 5 小时 / 每周 / 月度额度与重置倒计时。

### 渲染

- [**dsh-tex-block-normalizer**](https://github.com/tianzeluo/dsh-tex-block-normalizer)：修复 Pandoc 风格 `$$` 公式块被误解析的问题，避免公式首行丢失或整段变成 KaTeX 报错。

## 安装与使用

已开源的插件可以直接从 GitHub 安装，例如：

```bash
dsh plugin --profile web add github:tianzeluo/dsh-btw-sidebar
```

安装后重启 `dsh web` 并刷新页面。不同插件对 DSH 版本和 profile 的要求写在各自的 README 中。
