## Overview

DSH (DeepSeek Harness) is an extensible agent workspace. This collection gathers the plugins I have written for it, covering academic search, paper reading, session sidebars, desktop notifications, and math rendering.

The plugins follow one principle: fill a real gap in the workflow instead of wrapping the model in another layer. When a host seam can solve the problem, it should not cost an extra model turn; capabilities that stay on should be opt-in per project.

## Plugin categories

### Research and reading

- [**dsh-academic-search**](https://github.com/tianzeluo/dsh-academic-search): academic search across arXiv, OpenAlex, Semantic Scholar, and Crossref, with paper identity merging, bounded citation chains, and arXiv handoff.
- [**dsh-paper-reader**](https://github.com/tianzeluo/dsh-paper-reader): a paper-reading mode that produces reports with page and section anchors and answers follow-up questions from the same parsed source.

### Session and workflow

- [**dsh-btw-sidebar**](https://github.com/tianzeluo/dsh-btw-sidebar): a Codex-style `/btw` that forks the current conversation into the native right sidebar.
- [**dsh-away-notify**](https://github.com/tianzeluo/dsh-away-notify): desktop notifications for completion, errors, and approval waits, but only when you are away from the page.
- [**dsh-commandcode-quota**](https://github.com/tianzeluo/dsh-commandcode-quota): Command Code plan quotas and reset countdowns in the session header.

### Rendering

- [**dsh-tex-block-normalizer**](https://github.com/tianzeluo/dsh-tex-block-normalizer): repairs Pandoc-style `$$` math blocks that would otherwise lose their first line or swallow the rest of a message into a KaTeX error.

## Install and use

Published plugins can be installed directly from GitHub, for example:

```bash
dsh plugin --profile web add github:tianzeluo/dsh-btw-sidebar
```

Restart `dsh web` and refresh the page afterwards. Version and profile requirements for each plugin are documented in its own README.
